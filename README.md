## 🛠️ Ferramentas

As ferramentas e tecnologias utilizadas no desenvolvimento deste projeto foram:

* **[JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Linguagem de programação.
* **[Node.js](https://nodejs.org/):** Ambiente de execução do JavaScript no servidor.
* **[Express](https://expressjs.com/):** Framework para facilitar a criação de aplicações web e APIs.
* **[NPM](https://www.npmjs.com/):** Gerenciador de dependências e pacotes.
* **[Git](https://git-scm.com/):** Ferramenta de versionamento de código.
* **[GitHub](https://github.com/):** Plataforma para hospedagem do repositório.

## ⚙️ Pré-requisitos

Antes de baixar o projeto, certifique-se de ter instalado em sua máquina:
* [Git](https://git-scm.com)
* [Node.js](https://nodejs.org/) (Recomenda-se a versão LTS)

## 💻 Como executar o projeto localmente

Siga os passos abaixo no seu terminal para clonar e rodar a aplicação:

```bash
# Clone este repositório
$ git clone https://github.com/alerrandrohenrique/codificacao-back-end
# Acesse a pasta do projeto
$ cd codificacao-back-end

# Instale as dependências via NPM
$ npm install

# Execute a aplicação 
$ npm start
